# Check-in before building

**Q:** If only part of an order was returned, should the whole order be left out? Left out means it can't count as a first order or a second order. Options: Yes, leave out any order with a returned item; No, only leave out orders marked Returned as a whole. I'd suggest: Yes, leave out any order with a returned item, unless you prefer otherwise. (It changes which customers count as new or repeat buyers, so it moves each channel's repeat rate.)

**A:** No, only leave out orders that were fully returned or cancelled. If someone kept part of an order, they still made a real purchase, so it should count as a first or repeat order.

**Q:** If a customer places two separate orders on the same day, should the second one count as a repeat purchase? Options: No, a repeat must be on a later day; Yes, any second order counts, even on the same day. I'd suggest: No, a repeat must be on a later day, unless you prefer otherwise. (Same-day orders can look like a split basket, not a return visit, so counting them could raise the repeat rate for some channels.)

**A:** No, a repeat should be on a later day. Two orders on the same day are really one shopping trip, not a customer coming back.
